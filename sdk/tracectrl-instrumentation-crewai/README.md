# tracectrl-instrumentation-crewai

TraceCtrl instrumentation for [CrewAI](https://crewai.com). Automatically traces agent runs, tool calls, and LLM interactions to the TraceCtrl dashboard.

## Install

```bash
pip install tracectrl-instrumentation-crewai
```

## Usage

```python
from tracectrl.instrumentation.crewai import instrument
instrument()
```
