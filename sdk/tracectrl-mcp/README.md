# tracectrl-mcp

TraceCtrl MCP Proxy — transparent tool call tracing for IDE agents (Cursor, Claude Code, Windsurf). Sits between your MCP client and servers, recording every tool call as an OpenTelemetry span.

## Install

```bash
pip install tracectrl-mcp
```

## Usage

```bash
tracectrl-mcp --upstream http://localhost:3000
```
