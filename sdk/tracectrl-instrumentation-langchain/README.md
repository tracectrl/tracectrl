# tracectrl-instrumentation-langchain

TraceCtrl instrumentation for [LangChain](https://langchain.com) and [LangGraph](https://langchain-ai.github.io/langgraph/). Automatically traces agent runs, tool calls, and LLM interactions to the TraceCtrl dashboard.

## Install

```bash
pip install tracectrl-instrumentation-langchain
```

## Usage

```python
from tracectrl.instrumentation.langchain import instrument
instrument()
```
