# tracectrl-instrumentation-agno

TraceCtrl instrumentation for [Agno](https://agno.com). Automatically traces agent runs, tool calls, and LLM interactions to the TraceCtrl dashboard.

## Install

```bash
pip install tracectrl-instrumentation-agno
```

## Usage

```python
from tracectrl.instrumentation.agno import instrument
instrument()
```
