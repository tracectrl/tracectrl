# tracectrl-instrumentation-google-adk

TraceCtrl instrumentation for [Google Agent Development Kit (ADK)](https://google.github.io/adk-docs/). Automatically traces agent runs, tool calls, and LLM interactions to the TraceCtrl dashboard.

## Install

```bash
pip install tracectrl-instrumentation-google-adk
```

## Usage

```python
from tracectrl.instrumentation.google_adk import instrument
instrument()
```
